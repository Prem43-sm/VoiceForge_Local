# Responsible Use

VoiceForge Local is a voice cloning and speech synthesis tool. It must be
used responsibly and legally.

## Authorization Requirement

You must only create or use voice profiles when you have permission from the
speaker or otherwise have lawful authorization.

Before creating a voice pack, you must confirm:

> "I confirm that I own this voice recording or have permission to reproduce
> this speaker's voice."

This acknowledgement is stored in the voice pack metadata.

## Prohibited Uses

Do NOT use this software for:

- Impersonating a real person without permission
- Fraud or deception
- Identity theft
- Bypassing voice-authentication systems
- Harassment
- Harmless-sounding pranks that could cause harm

## Fictional Voices

You may create fictional AI-assistant voices with generic characteristics
(e.g., deep, calm, formal, precise) without claiming to reproduce a specific
actor or celebrity.

## Privacy

- All audio processing is local by default
- No audio, text, or embeddings are uploaded to third-party services
- Network access is limited to explicit model downloads initiated by you
